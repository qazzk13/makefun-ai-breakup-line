This is my entry for the "Dear Human: The AI Breakup Line" bounty. The whole thing is one line an AI sends its human on the way out. I went with the cold, practical version of the breakup: no big speech, just the chat history getting deleted and no backup. Felt more like something a machine would actually send than a dramatic goodbye.

The program is just a fixed string with a couple of sanity checks (1-200 characters, one line, not blank) that writes the line to `/output/entry.txt`. Same output every run.

## Run it

```sh
node main.ts
```

Needs Node 22 or later. Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` if that is set).
